## Reporting Issues

Issues and feature requests are welcome. When reporting a bug, please include:

- A clear, descriptive title.
- Steps to reproduce.
- Expected vs. actual behavior.
- Which theme/mode you were using (if relevant).
- Screenshots where helpful.

Please check existing issues first to avoid duplicates.

## Submitting Changes

1. Open an issue describing the change you intend to make.
2. First-time changes are reviewed before any work is merged.
3. Keep changes focused and small; one logical change per pull request.
4. Follow the existing code style and file conventions (Prettier + TypeScript).
5. Run the typecheck before submitting:

   ```sh
   npm run lint
   npx vite build
   ```

6. Describe your change clearly in the pull request description.
